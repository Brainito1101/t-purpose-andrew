## Instructions for Creating Payment Links

### In Stripe:
1. Go to Products → Create Product
2. Enter the product name from above
3. Set the price (one-time or recurring)
4. Create payment link
5. Copy the payment link URL

### In GoHighLevel:
1. Go to Payments → Products
2. Create new product with name from above
3. Set price
4. Create payment link
5. Copy the payment link URL

### Important Notes:
- **Links 1-16**: One-time payments
- **Links 17-24**: Subscriptions (first payment + recurring monthly)
- Keep the "Key" column handy - you'll need it for code integration
- Save all 24 payment URLs in a spreadsheet with their corresponding keys
